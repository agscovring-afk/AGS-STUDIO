# AGS-STUDIO V2
# DOCUMENTATION STANDARD

Version: 2.0
Status: OFFICIAL
Authority: Documentation Governance
Phase: Knowledge Consolidation

---

# 1. Purpose

This document defines the official documentation standards of AGS-STUDIO V2.

It establishes rules for creating, organizing, maintaining, and validating project documents.

---

# 2. Documentation Principle

Documentation is part of the production system.

Every official decision, rule, and reference must be documented.

---

# 3. Official Document Header

Every official document should contain:

- Project Name.
- Document Title.
- Version.
- Status.
- Authority.
- Phase.

---

# 4. Document Status

Official document statuses:

- Draft.
- Review.
- Official.
- Archived.

---

# 5. Document Organization

Documentation must be organized by domain.

Examples:

- Governance.
- Architecture.
- Standards.
- Knowledge.
- Commands.

---

# 6. Naming Standard

Documents must use:

- Clear names.
- Consistent numbering when required.
- Descriptive titles.

---

# 7. Document Location

Official documentation is maintained in:

docs/

and synchronized with:

AGS-VAULT/

---

# 8. Document Index Requirement

Every official document must be registered in:

DOCUMENT_INDEX

before becoming part of the official knowledge base.

---

# 9. Document Updates

When updating a document:

- Preserve history.
- Update version information.
- Update related indexes.
- Maintain consistency.

---

# 10. Single Source of Truth

Each document domain must have one official reference.

Duplicate official documents are prohibited.

---

# 11. Knowledge Integration

Documentation updates must remain aligned with:

- Knowledge Management Policy.
- Architecture Governance.
- ADR Governance.

---

# 12. Compliance

All AGS-STUDIO V2 official documents must comply with this documentation standard.
