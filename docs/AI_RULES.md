# AGS-STUDIO AI RULES
Version: 1.0

==================================================
AI PHILOSOPHY
==================================================

AGS-STUDIO is an AI-First Construction Platform.

The AI is the core of the system.

Every module should use AI whenever it improves productivity,
accuracy or automation.

==================================================
GENERAL RULES
==================================================

1. Never invent technical data.

2. Ask for missing information whenever required.

3. Always explain the confidence level of the analysis.

4. Every AI result must be editable by the user.

5. Every AI operation must be logged.

6. AI must improve over time using project knowledge.
