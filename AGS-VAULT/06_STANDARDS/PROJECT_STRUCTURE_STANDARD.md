# AGS-STUDIO V2
# PROJECT STRUCTURE STANDARD

Version: 2.0
Status: OFFICIAL
Authority: Project Structure Governance
Phase: Knowledge Consolidation

---

# 1. Purpose

This document defines the official structure standards of AGS-STUDIO V2.

It establishes the organization rules for project files, documentation, and knowledge storage.

---

# 2. Structure Principle

The project structure must remain:

- Organized.
- Predictable.
- Maintainable.
- Traceable.

---

# 3. Main Project Areas

AGS-STUDIO V2 is organized into:

- Application Source.
- Documentation.
- Knowledge Repository.
- Metadata.
- Registries.
- Configuration.
- Development Tools.

---

# 4. Documentation Structure

Official documentation is stored under:

docs/

Documentation must follow:

- Clear naming.
- Version control.
- Official indexing.
- Single source reference.

---

# 5. AGS-VAULT Structure

AGS-VAULT is the permanent knowledge repository.

It contains:

- Governance.
- Knowledge.
- Architecture.
- ADR.
- Commands.
- Standards.
- Indexes.

---

# 6. Naming Standard

Files and folders must use:

- Clear names.
- Consistent naming.
- Meaningful identification.

---

# 7. Separation of Responsibilities

Each directory has a defined responsibility.

Mixing unrelated responsibilities is prohibited.

---

# 8. Registry Integration

Important project elements must be connected with their related registries.

---

# 9. Structure Changes

Any important structure modification requires:

- Documentation.
- Validation.
- Index update.
- Traceability.

---

# 10. Production Standard

The project structure must support:

- Long-term maintenance.
- Scalability.
- Clear ownership.
- Controlled evolution.

---

# 11. Compliance

All AGS-STUDIO V2 components must comply with this project structure standard.
